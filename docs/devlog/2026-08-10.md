# Devlog — week of 2026-08-10

## Focus: closing the external security review (AK-001 … AK-012)

The AgentDock review landed with three P0s and a long tail. This week was
entirely remediation, in dependency order.

**Sandboxing (AK-001).** The uncomfortable finding: on macOS the local
backend's shell path was just `/bin/sh -c` in a cwd. The fix is a probed,
verified sandbox layer — bubblewrap on Linux, Seatbelt on macOS — where the
probe actually executes a canary inside the candidate sandbox and then
proves a host file outside the workspace is unreadable before we report any
isolation strength. No sandbox → shell fails closed with a routable error.
The compiled confinement (readable/writable prefixes) now materializes as
bind mounts / SBPL subpath rules, and *all* direct egress is denied at the
sandbox: domain allowlists belong to connectors, where they can be enforced
on resolved addresses instead of being theater.

**AuthN/Z (AK-002).** The control plane now has a bearer-token layer with
constant-time digest comparison, principal binding (bodies can no longer
name arbitrary principals), role gates (admin/approver/agent) and ownership
checks on every episode/branch/effect route. The server binary refuses
non-loopback listens without an auth config.

**The rest.** Atomic commit claims and an in-doubt recovery protocol for
the broker; atomic lease consumption and per-episode budget reservation;
DNS-resolution SSRF defense with IP pinning in the HTTP connector;
self-merge rejection and CAS integrity verification in the DAG; sealed
vault and signing seed; episode metadata persistence so restarts stop
404ing; replay re-authorization under compiled confinement; the OpenAPI
spec regenerated from the real router; both SDK bugs (shared
AbortController, unclosed HTTPError) fixed with regression tests.

Verified end-to-end against a real server: 401 without a token, 403 on
principal spoofing, role separation on trace/approve, restart recovery of
episodes, sealed vault refusing a wrong key. All gates green: fmt, clippy
`-D warnings`, rustdoc `-D warnings`, full workspace tests, both SDKs.
