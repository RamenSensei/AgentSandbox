# Devlog — 2026-08-14

The backend data plane now follows the same invariant as the state DAG:
mutable execution is allowed, but only a committed, exact state may become
the base of another transition.

## Landed

- Remote forkd/Cube excursions are real transitions end to end. The kernel
  validates and transactionally applies returned deltas, records chmod-only
  and file/directory shape changes, and rejects profile/outcome disagreement.
- One branch has one movable transition at a time; independent branches stay
  parallel. Remote CoW uses only a quiescent sandbox with a complete manifest
  equal to the requested state. Ambiguous exec/sync failures poison that
  sandbox, and fork/merge/discard drive adapter lifecycle cleanup. The live
  tree is re-listed before sync-in and CoW, so retained-process drift cannot
  turn a manifest cache into false state authority. Sync-out re-lists the
  complete tree after pulling every changed blob, rejecting a mixed-time
  delta if a retained process moved any path during the download. CoW also
  verifies the resulting clone, not just its selected source, before claiming
  native success.
- Linux bwrap egress has a required CI path through the in-netns forwarder.
  Proxy accounting cannot exceed the byte cap or charge cancelled writes,
  grant revocation reaches established tunnels, and listener/probe resources
  have bounded lifetimes. The same listener now speaks authenticated SOCKS5
  and injects `ALL_PROXY`, extending the policy-preserving route to non-HTTP
  TCP clients without adding a second enforcement model.
- Probe-verified cgroup v2 enforcement covers the whole shell or process-
  session tree: aggregate CPU, memory and PID ceilings, atomic tree kill and
  kernel-sourced diagnostics. The probe verifies cgroup2 `statfs` identity,
  not merely lookalike writable files. Linux CI delegates a real hierarchy
  and fails if these tests silently skip; macOS performs compile and fallback
  tests.

The implementation deliberately keeps one state model and one fallback:
exact native CoW when proven, otherwise content-addressed materialization.
There is no second shadow state machine and no PID-enumeration kill fallback.
