# Devlog — week of 2026-08-13

Release: **v0.8.0**, the enablement release. The external utility review
(post-0.7.0) reframed the goal: the kernel was good at *governing* an
agent and not yet good at *releasing* one. This week the execution data
plane caught up with the control-plane semantics.

## Landed

- **Observation/effect plane split on the main path.** `HttpRead` and
  manifest-vouched `Pure` MCP tools execute inline in one step;
  everything else automatically becomes a proposed effect. Per-invocation
  classification (`Connector::classify_operation`) runs before contract
  creation, so allowlisted reads never queue behind human approval.
- **Transparent egress proxy.** Steps whose confinement grants egress
  domains get standard proxy environment with a per-step bearer token:
  `pip install` / `cargo fetch` / `git fetch` work unmodified while
  domain globs, SSRF guards (pinned resolved addresses), a port
  allowlist and byte caps are enforced at the one hop out. Seatbelt
  opens *only* the proxy port; bwrap keeps egress off — honest
  fail-closed until an in-namespace forwarder lands.
- **Persistent process sessions.** `process_start` / stdin / offset-based
  logs / signal / status; branch-scoped, sandboxed, die with the branch.
- **MCP trust boundary closed.** `KernelConfig.mcp` spawns servers as
  confined low-trust tool processes: OS sandbox wrapper, scrubbed env,
  private scratch cell, profile stored outside the cell. Fail closed
  without a verified sandbox.
- **Autonomy envelopes.** `compile_envelope` requests everything a task
  needs in one call; granted leases are exactly what `execute_auto`
  resolves — approve a capability space, not one command at a time.
- **Honest metering.** Shell children are reaped with `wait4`: real
  user+sys CPU and peak RSS replace wall-clock/byte-count proxies, and
  timeout kills now take down the whole process group (proven against a
  backgrounded grandchild).
- **Incremental tiered snapshots**, head+tail observation distillation,
  denials as recovery plans, server-side `explore`, raw-output paging
  and grep — all on the main path with tests.

## Carried forward

- Backend registration/routing config (multi-backend still embedder-wired).
- Linux in-namespace egress forwarder (bwrap hosts stay offline).
- cgroup *enforcement* (metering is honest now; hard limits are not).
- A real-LLM end-to-end benchmark next to the scripted utility bench.
